# 📊 Customer Churn Prediction Using Machine Learning

An end-to-end Machine Learning project that predicts whether a customer is likely to **churn** or **stay** based on customer demographics, services, contract information, usage, and billing details.

The project includes complete data preprocessing, exploratory data analysis, machine learning model training, model evaluation, feature importance analysis, and a Flask-based web application for real-time customer churn prediction.

---

## 🚀 Project Overview

Customer churn is one of the biggest challenges faced by subscription-based businesses.

When customers stop using a company's products or services, the business loses revenue and may also spend additional money trying to acquire new customers.

This project uses Machine Learning to identify customers who are at risk of leaving.

The system analyzes customer information and produces:

- Customer churn prediction
- Churn probability
- Risk level
- Model performance metrics
- Confusion matrix
- ROC curve
- Feature importance
- Interactive web-based prediction

The final application allows a user to enter customer information through a web interface and receive an AI-powered churn prediction.

---

# 🎯 Project Objectives

The main objectives of this project are:

1. Analyze customer data.
2. Identify patterns associated with customer churn.
3. Preprocess numerical and categorical data.
4. Train Machine Learning classification models.
5. Compare different classification algorithms.
6. Select the best-performing model.
7. Evaluate the model using multiple metrics.
8. Save the trained Machine Learning model.
9. Build a Flask web application.
10. Provide real-time customer churn predictions.
